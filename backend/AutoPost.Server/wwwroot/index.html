ตั้งค่าจากที่ไหนก็ได้ เครื่องรันดึง config จาก server เอง

Config (ชุดตั้งค่า)

1 config = ชุดโพสต์ กลุ่ม ข้อความ รูป เวลา Telegram ทั้งหมด กด "แก้ไข" เพื่อเปิดหน้าตั้งค่าแบบเดียวกับในส่วนขยาย หลายเครื่องใช้ config เดียวกันได้

เครื่องรัน (คอมที่ติดตั้งส่วนขยาย)

แต่ละเครื่องมี "คีย์เครื่อง" ของตัวเอง ใส่คีย์ในหน้าตั้งค่าส่วนขยายของเครื่องนั้น (การ์ด "เชื่อมต่อ server") แล้วเครื่องจะดึง config ที่เลือกไว้ทุก 30 วินาที

คีย์ของเครื่อง

คีย์แสดงครั้งเดียว คัดลอกไปใส่ในเครื่องนั้นเลย (ถ้าหาย กด "ออกคีย์ใหม่")

  1. เปิดหน้าตั้งค่าส่วนขยายบนเครื่องนั้น (คลิกไอคอน FB AutoPost)
  2. การ์ด "เชื่อมต่อ server (ตั้งค่าออนไลน์)" ใส่ URL server และคีย์ แล้วกด "เชื่อมต่อ"
  3. ถ้า config บน server ยังว่าง เครื่องจะอัปโหลดการตั้งค่าที่มีอยู่ขึ้นมาให้ ถ้ามีแล้ว เครื่องจะใช้ config จาก server

# FB Group AutoPost (Human-like) — Chrome Extension

ส่วนขยาย Chrome สำหรับโพสต์ลงกลุ่ม Facebook อัตโนมัติ โดยทำทุกขั้นแบบสุ่ม ให้เหมือนคนโพสต์เอง

## ความสามารถ

| ต้องการ | ทำได้ |
|---|---|
| โพสต์อัตโนมัติแบบเหมือนคน | เปิดกลุ่ม → เลื่อนดูฟีดแบบสุ่ม → คลิกช่อง "เขียนอะไรสักหน่อย..." → พิมพ์ทีละตัวด้วยจังหวะสุ่ม (มีหยุดคิด, พิมพ์ผิดแล้วลบ) → แนบรูป → รอสักครู่ → กด "โพสต์" |
| ใส่ลิงก์กลุ่ม | ตารางกลุ่ม 1 แถวต่อ 1 กลุ่ม หรือวางหลายลิงก์พร้อมกัน รองรับ `facebook.com/groups/...`, `m.facebook.com`, `web.facebook.com` ระบบตรวจลิงก์ผิดและลิงก์ซ้ำให้ |
| กำหนดเนื้อหา + แนบรูป | ใส่ได้หลายแบบโพสต์ แต่ละแบบมีข้อความและรูปหลายรูป รองรับคำสุ่ม `{สวัสดี\|หวัดดี}` |
| หน่วงเวลาแต่ละกลุ่ม | สุ่มเวลาในช่วง ต่ำสุด–สูงสุด (นาที) ทุกกลุ่ม และสุ่มพักยาวเป็นระยะ |
| เว้นแต่ละรอบกี่ชั่วโมง | ตั้งชั่วโมงพักหลังโพสต์ครบทุกกลุ่ม + สุ่มบวกเวลาเพิ่ม แล้วเริ่มรอบใหม่เอง |
| จัดเป็นชุดโพสต์ | แต่ละ **ชุด** มีกลุ่ม, เนื้อหา, เวลาหน่วง, เว้นรอบ และพฤติกรรมสุ่มของตัวเอง เช่น ชุด "ขายของ" โพสต์ 10 กลุ่ม ทุก 6 ชม. ชุด "รับสมัคร" โพสต์อีก 5 กลุ่ม ทุก 12 ชม. ทุกชุดทำงานพร้อมกัน แต่โพสต์จริงทีละ 1 โพสต์ |
| ข้อความเฉพาะกลุ่ม | ใส่ข้อความแยกแต่ละกลุ่มได้ (เช่น รหัสการซื้อการเข้ากลุ่ม) ระบบใส่ไว้ **บรรทัดแรก** ของโพสต์ หรือตรง `{{code}}` ถ้าใส่ไว้ในเนื้อหา ไม่ใส่ก็ได้ |
| ไม่เลือกคำที่ Facebook แนะนำ | ตอนพิมพ์ `#แท็ก` หรือ `@ชื่อ` Facebook จะขึ้นคำแนะนำ ระบบไม่กด Enter เลย (ขึ้นบรรทัดใหม่ด้วยการวางตัวขึ้นบรรทัดแทน) ข้อความจึงตรงกับที่พิมพ์ทุกตัว |
| ข้อความเพิ่มในทุกโพสต์ | ตั้งต่อชุดได้ เช่น ลิงก์เว็บไซต์และผลงาน ใส่ต่อจากบรรทัดทักทาย (ขออนุญาต… / สวัสดี…) หรือท้ายโพสต์ |
| กันโดนบล็อก + เนื้อหาหมุนเวียน | ไม่ใช้โพสต์ซ้ำในกลุ่มเดิม, โควตาต่อวัน, พักกลุ่มเดิม, หยุดพักเองเมื่อ Facebook เตือนแล้วทำต่ออัตโนมัติ |
| สื่อนำหน้าทุกโพสต์ | รูป/วิดีโอที่แนบเป็นไฟล์แรกของทุกโพสต์ในชุด เช่น โปสเตอร์ + วิดีโอแนะนำร้าน |
| นำเข้า SIRI export | แปลงไฟล์ `SIRI_autopost_export.zip` (โพสต์, รูป, กลุ่ม) เป็นชุดโพสต์ แต่ละโพสต์ผูกกับกลุ่มเดิมของมัน |
| ย้ายเครื่องแล้วใช้ได้ทันที | บันทึกทุกอย่าง (โพสต์, รูป, กลุ่ม, การตั้งค่า) เป็น `config/autopost-config.json` ในโฟลเดอร์ส่วนขยาย ก๊อปโฟลเดอร์ไปเครื่องใหม่ + Load unpacked = โหลดให้เอง |
| ดาวน์โหลด / อัปโหลดการตั้งค่า | สำรองทุกอย่าง (ชุด, กลุ่ม, ข้อความ, รูป, การตั้งค่า) เป็นไฟล์ .json แล้วนำกลับมาแบบแทนที่หรือเพิ่มเป็นชุดใหม่ |
| แจ้งเตือน Telegram + ภาพหน้าจอ | แจ้งทุกโพสต์ว่ากลุ่มไหนสำเร็จ/ไม่สำเร็จ (พร้อมภาพหน้าจอและสาเหตุ) กลุ่มที่โพสต์ไม่ได้จะข้ามไปทันที และสรุปรายชื่อกลุ่มทุกครั้งที่จบรอบ |

### พฤติกรรมแบบสุ่ม

- สุ่มลำดับกลุ่มใหม่ทุกรอบ
- สุ่มเนื้อหาโพสต์ (ไม่ซ้ำแบบเดิมติดกัน) และสุ่มคำด้วย spintax
- สุ่มเวลาหน่วงระหว่างกลุ่ม (กระจายตัวแบบสามเหลี่ยม ค่าจะออกแถวกลางช่วงบ่อยกว่าขอบ)
- สุ่มพักยาวเฉลี่ยทุก N โพสต์
- สุ่มข้ามบางกลุ่มในบางรอบ (ตั้ง % ได้)
- สุ่มจำนวนครั้ง/ระยะการเลื่อนดูฟีดก่อนโพสต์
- สุ่มจังหวะพิมพ์ ความเร็วแต่ละครั้งไม่เท่ากัน มีหยุดคิดหลังเว้นวรรค/จุด
- สุ่มพิมพ์ผิดแล้วกดลบแก้
- สุ่มจุดคลิกบนปุ่ม และส่ง event เมาส์ครบชุด (over/move/down/up/click)
- สุ่มเวลาเริ่มรอบใหม่ (บวก 0–N นาที) และเวลาเริ่มช่วงทำงาน
- ข้อความยาวเกินที่ตั้งไว้จะ "วาง" ทีเดียวเหมือนคนก๊อปมาวาง

## ติดตั้ง

1. เปิด Chrome ไปที่ `chrome://extensions`
2. เปิด **Developer mode** (มุมขวาบน)
3. กด **Load unpacked** แล้วเลือกโฟลเดอร์ `C:\ProjectAutoPost`
4. ปักหมุดไอคอนส่วนขยาย แล้วคลิกไอคอนเพื่อเปิดหน้าตั้งค่า

ต้องล็อกอิน Facebook ใน Chrome โปรไฟล์เดียวกันไว้ก่อน และต้องเป็นสมาชิกกลุ่มที่จะโพสต์

## วิธีใช้

1. **ชุดโพสต์**: แท็บด้านบนคือชุดโพสต์ กด "+ เพิ่มชุด" เพื่อสร้างชุดใหม่ ตั้งชื่อ และติ๊ก "เปิดใช้ชุดนี้"
   - "ทำสำเนาชุด" คัดลอกทั้งกลุ่ม เนื้อหา รูป และการตั้งค่า (สำเนาปิดไว้ก่อน)
2. **กลุ่มในชุดนี้**: กด "+ เพิ่มกลุ่ม" แล้วใส่ลิงก์ ช่องขวาคือ **ข้อความเฉพาะกลุ่ม** (ไม่ใส่ก็ได้)
   - ติ๊กหน้าแถวออกเพื่อปิดกลุ่มนั้นชั่วคราว
   - ช่อง **โพสต์ได้ … /วัน** = กฎของกลุ่มว่าโพสต์ได้กี่ครั้งใน 24 ชม. เช่น 1 หรือ 3, **0 = ไม่จำกัด** (ดูหัวข้อ "จำนวนโพสต์ต่อวันของแต่ละกลุ่ม")
   - "เพิ่มหลายกลุ่มพร้อมกัน": วางบรรทัดละกลุ่ม ใส่ข้อความเฉพาะกลุ่มหลัง `|` และจำนวนโพสต์ต่อวันใน `[ ]` เช่น
     `https://www.facebook.com/groups/123 [1/วัน] | รหัสซื้อเข้ากลุ่ม: AB12` (หรือ `[วันละ 3]`, `[ไม่จำกัด]`)
   - กลุ่มที่มีในชุดอยู่แล้วไม่เพิ่มซ้ำ แต่ถ้าบรรทัดนั้นมี `| ข้อความ` ระบบเปลี่ยนข้อความเฉพาะกลุ่มเป็นข้อความใหม่ (ใช้เปลี่ยนรหัสหลายกลุ่มพร้อมกัน)
3. **เนื้อหาโพสต์**: พิมพ์ข้อความ กด "+ แนบรูป" เพิ่มรูป กด "+ เพิ่มแบบโพสต์" ถ้าต้องการหลายแบบ
   - ใช้ `{คำ1|คำ2|คำ3}` เพื่อสุ่มคำ ซ้อนกันได้ เช่น `{ขาย{ด่วน|ถูก}|ปล่อยต่อ}`
   - ข้อความเฉพาะกลุ่มจะขึ้น **บรรทัดแรก** อัตโนมัติ ถ้าต้องการวางที่อื่น ให้ใส่ `{{code}}` (หรือ `{{รหัส}}`) ตรงตำแหน่งนั้น
   - กลุ่มที่ไม่มีข้อความเฉพาะ จะไม่มีบรรทัดเพิ่ม และบรรทัดที่มีแค่ `{{code}}` จะถูกลบออก
   - กด "ดูตัวอย่างสุ่ม" เพื่อดูผลลัพธ์ (สุ่มกลุ่มที่มีข้อความเฉพาะมาแสดง)
4. **หน่วงเวลา และรอบ (ของชุดนี้)**: หน่วงระหว่างกลุ่ม (นาที), เว้นระหว่างรอบ (ชั่วโมง), จำนวนรอบสูงสุด, ช่วงเวลาทำงาน
5. **พฤติกรรมแบบสุ่ม (ของชุดนี้)**: เลือกตามต้องการ (ค่าเริ่มต้นใช้ได้เลย)
6. **ตั้งค่ารวม**: "เว้นห่างขั้นต่ำระหว่างโพสต์ทุกชุด" กันไม่ให้หลายชุดโพสต์ติด ๆ กัน
7. **ทดสอบโพสต์ 1 กลุ่ม**: เลือกกลุ่ม/เนื้อหา กด "ดูข้อความที่จะโพสต์" เพื่อดูข้อความจริง แล้วกด **ทดสอบเลย** (โพสต์จริง)
8. กด **เริ่มทำงาน** ทุกชุดที่เปิดใช้จะเริ่ม (เหลื่อมเวลากันแบบสุ่ม) ดูสถานะแต่ละชุดในการ์ด "ภาพรวมทุกชุด"

ระหว่างทำงาน:
- เปิดชุดใหม่: ชุดนั้นจะเริ่มเองในไม่กี่นาที
- ปิดชุด: ชุดนั้นหยุด ชุดอื่นทำต่อ
- ชุดที่ครบจำนวนรอบจะหยุดเอง ถ้าครบทุกชุด ระบบหยุดทั้งหมด
- ปุ่ม "โพสต์กลุ่มถัดไปของชุดนี้ทันที" ข้ามเวลารอของชุดนั้น

ทุกค่าบันทึกอัตโนมัติ ค่าจากเวอร์ชันแรก (รายการกลุ่มเดียว) จะถูกย้ายเป็น "ชุดที่ 1" ให้เอง

## ย้ายไปเครื่องอื่น แล้วใช้งานได้ทันที (ไฟล์ config)

ไฟล์ `config/autopost-config.json` ในโฟลเดอร์ส่วนขยายเก็บ **ทุกอย่าง**: ชุดโพสต์, ลิงก์กลุ่ม, ข้อความเฉพาะกลุ่ม (รหัส), ข้อความโพสต์, **รูป**, เวลาหน่วง/เว้นรอบ, พฤติกรรมสุ่ม, ตั้งค่ารวม, Telegram

**สร้าง/อัปเดตไฟล์ config** (บนเครื่องที่ตั้งค่าไว้แล้ว):
1. หน้าตั้งค่า > การ์ด "สำรอง / ย้ายการตั้งค่า" > กล่อง "ไฟล์ config สำหรับย้ายเครื่อง"
2. เลือก "รวม Telegram Bot Token" (ค่าเริ่มต้น เปิด) และ "เริ่มทำงานให้อัตโนมัติเมื่อเปิดบนเครื่องใหม่" (ค่าเริ่มต้น ปิด)
3. กด **บันทึก config ลงโฟลเดอร์ส่วนขยาย** แล้วเลือกโฟลเดอร์ส่วนขยาย (เช่น `C:\ProjectAutoPost`) > `config` > บันทึกทับ `autopost-config.json`
4. กล่องสถานะจะขึ้น "พบไฟล์ config บันทึกเมื่อ ... : x ชุด · y กลุ่ม · z รูป" แปลว่าบันทึกถูกที่แล้ว

ทำข้อ 3 ใหม่ทุกครั้งที่แก้การตั้งค่าและอยากให้ไฟล์ config เป็นเวอร์ชันล่าสุด

**ใช้บนเครื่องใหม่**:
1. คัดลอก **ทั้งโฟลเดอร์ส่วนขยาย** (รวม `config/autopost-config.json`) ไปเครื่องใหม่
2. `chrome://extensions` > เปิด Developer mode > **Load unpacked** > เลือกโฟลเดอร์นั้น
3. ส่วนขยายโหลด config ให้เองทันที เปิดหน้าตั้งค่าจะเห็นทุกชุด/กลุ่ม/โพสต์/รูปครบ
4. ล็อกอิน Facebook ใน Chrome เครื่องใหม่
5. ถ้าใช้ภาพหน้าจอ Telegram: กด "อนุญาตจับภาพหน้าจอ" 1 ครั้ง (Chrome บังคับให้ผู้ใช้กดเอง)
6. กด **เริ่มทำงาน** (หรือถ้าบันทึกแบบ "เริ่มทำงานอัตโนมัติ" ระบบเริ่มเองตั้งแต่ข้อ 2)

กฎการโหลดอัตโนมัติ:
- โหลดเองเฉพาะตอนที่ Chrome นั้น **ยังไม่มีข้อมูล** (ติดตั้งใหม่ / ย้ายเครื่อง / ลบชุดหมดแล้ว) ข้อมูลที่แก้ในเครื่องนั้นจะไม่ถูกทับ
- ปุ่ม **โหลด config จากโฟลเดอร์** ใช้บังคับโหลดทับเอง (ต้องกด "หยุด" ก่อน) ถ้าไฟล์ไม่มี Bot Token ระบบใช้การตั้งค่า Telegram เดิมของเครื่องนั้นทั้งหมด (Token, Chat ID, ตัวเลือกการแจ้ง)
- ถ้าไฟล์เสีย ระบบไม่โหลดและแจ้งในบันทึกการทำงาน

ข้อควรระวัง: ถ้าบันทึกแบบรวม Bot Token ห้ามแชร์โฟลเดอร์ส่วนขยายให้คนอื่น

## ตั้งค่าออนไลน์ (server .NET + PostgreSQL)

ตั้งค่าจากที่ไหนก็ได้ (มือถือ / คอมเครื่องอื่น) ผ่านหน้าเว็บของ server แล้ว **เครื่องรัน** (Chrome ที่ติดตั้งส่วนขยาย) ดึง config ไปใช้เอง

```
หน้าเว็บ (ที่ไหนก็ได้) ──แก้ config / กดเริ่ม-หยุด──▶ server (.NET 10 + PostgreSQL)
                                                        ▲
เครื่องรัน (ส่วนขยาย) ──ทุก 30 วินาที: ดึง config, ส่งสถานะ+บันทึก, รับคำสั่ง──┘
```

- **config** = ชุดโพสต์ กลุ่ม ข้อความ รูป เวลา Telegram ทั้งหมด (แบบเดียวกับในส่วนขยาย) มีได้หลาย config
- **เครื่องรัน** = คอมแต่ละเครื่อง มีคีย์ของตัวเอง เลือกได้ว่าใช้ config ไหน หลายเครื่องใช้ config เดียวกันได้
- หน้าแก้ config บนเว็บ **คือหน้าตั้งค่าเดียวกับในส่วนขยาย** (ใช้ไฟล์ `dashboard.*` ชุดเดียวกัน) มีครบทุกอย่าง: ชุด กลุ่ม โพสต์ รูป/วิดีโอ นำเข้า/ส่งออกไฟล์ นำเข้า SIRI zip ภาพรวม บันทึกการทำงาน ปุ่มเริ่ม/หยุด/ทดสอบโพสต์ (สั่งไปที่เครื่องที่เลือกไว้ด้านบน)

### ติดตั้ง server

**แบบ Docker (แนะนำสำหรับ VPS)** จากโฟลเดอร์ `server/`:
```bash
cp .env.example .env    # แก้ DB_PASSWORD, ADMIN_PASSWORD
docker compose up -d --build
```
เปิด `http://<server>:8080` ล็อกอินด้วย `ADMIN_USER` / `ADMIN_PASSWORD`
ใช้ผ่านอินเทอร์เน็ตต้องมี **HTTPS** ด้านหน้า (Caddy / Nginx / Cloudflare Tunnel) เพราะคีย์เครื่องและรหัสผ่านวิ่งผ่านเส้นนี้

**แบบรันเอง (Windows/Linux ที่มี .NET 10 SDK + PostgreSQL)**:
1. ฐานข้อมูล: server อ่าน `server/.env` เอง ใช้ `ConnectionStrings__Default` ถ้ามี ถ้าไม่มีใช้ `AppSettings__ConnectionStrings` (server Postgres เดียวกับระบบ SIRI)
   แล้วเปลี่ยนชื่อฐานตาม `Database:Name`: **dev** (`ASPNETCORE_ENVIRONMENT=Development`, `dotnet run`) = `SIRIAUTOPOST`, **production** (ค่าเริ่มต้น / Docker) = `SIRIAUTOPOST_PRD`
   ระบบสร้างฐานและตารางให้เองตอนเริ่มครั้งแรก (user ของฐานต้องมีสิทธิ์ CREATEDB ถ้าไม่มี ให้สร้างฐานเองก่อน: `CREATE DATABASE "SIRIAUTOPOST" OWNER app_user;`)
   ตารางทุกตัวชื่อขึ้นต้น `fbap_` และประวัติ migration อยู่ใน `fbap_ef_migrations`
   ตั้งรหัสแอดมินด้วย `Admin__Password=...` ใน `.env` (หรือ `appsettings.json` > `Admin:Password`)
2. `cd backend/SIRI.AUTOPOST.Server` แล้ว `dotnet run` (พอร์ต 5080) หรือ `dotnet publish -c Release` แล้วรัน `SIRI.AUTOPOST.Server.dll`
3. ถ้าไม่ตั้ง `Admin:Password` ระบบสุ่มรหัสให้ครั้งแรกและพิมพ์ไว้ใน log ของ server เปลี่ยนรหัสได้ในหน้าเว็บ

### เชื่อมเครื่องรัน
1. หน้าเว็บ server > **Config** > สร้าง config (เริ่มจากว่าง หรือคัดลอกจากที่มี)
2. **เครื่องรัน** > ใส่ชื่อเครื่อง เลือก config > **เพิ่มเครื่อง** > ได้ URL server + **คีย์เครื่อง** (แสดงครั้งเดียว)
3. บนเครื่องรัน: เปิดหน้าตั้งค่าส่วนขยาย > การ์ด **เชื่อมต่อ server (ตั้งค่าออนไลน์)** > ใส่ URL + คีย์ > **เชื่อมต่อ**
   - config บน server ยังว่าง → อัปโหลดการตั้งค่าที่เครื่องนี้มีขึ้นไปให้ (ย้ายของเดิมขึ้น server ได้ทันที)
   - config บน server มีข้อมูลแล้ว → เครื่องนี้ใช้ของ server แทนของเดิม
4. จากนั้นแก้ที่หน้าเว็บ (Config > **แก้ไข** หรือ เครื่องรัน > **ควบคุม / ดูสถานะ**) เครื่องรันได้ของใหม่ภายใน ~30 วินาที

### กฎการซิงก์
- server เก็บ "ฉบับที่" (revision) ของ config แก้ครั้งไหนก็เพิ่มขึ้น เครื่องรันเห็นฉบับใหม่ก็ดึงมาแทนที่ (รูปที่ยังไม่มีดึงมาเฉพาะรูปนั้น)
- แก้ในหน้าตั้งค่าของเครื่องรันเองก็ได้ ระบบส่งขึ้น server ให้ภายในไม่กี่วินาที
- แก้ทั้งสองที่พร้อมกัน → **ใช้ของ server** (มีบันทึกเตือน) หน้าเว็บสองหน้าที่แก้ config เดียวกันพร้อมกัน หน้าที่บันทึกทีหลังจะถูกบอกให้โหลดใหม่
- config บน server ไม่มี Bot Token → เครื่องรันใช้ Telegram เดิมของตัวเอง (กฎเดียวกับไฟล์ config)
- ปุ่มในการ์ดของเครื่องรัน: **ซิงก์ตอนนี้**, **ดึง config จาก server** (แทนที่ของเครื่อง), **อัปโหลดของเครื่องนี้ขึ้น server** (เขียนทับ server), **ยกเลิกการเชื่อมต่อ**
- คำสั่งจากเว็บ (เริ่ม / หยุด / โพสต์ทันที / ทดสอบโพสต์ / ทดสอบ Telegram) ไปถึงเครื่องรันภายใน ~30 วินาที คำสั่งที่ค้างเกิน 10 นาที (เครื่องปิดอยู่) จะถูกทิ้ง ไม่ทำย้อนหลัง
- เครื่องรันต้องเปิด Chrome ไว้และล็อกอิน Facebook ตามเดิม server ไม่ได้โพสต์เอง
- "อนุญาตจับภาพหน้าจอ" ยังต้องกดที่เครื่องรันเอง 1 ครั้ง (Chrome บังคับ)
- ออกคีย์ใหม่ / ลบเครื่องบนเว็บ = คีย์เดิมใช้ไม่ได้ทันที

**ทางที่ 1: ผ่านหน้าตั้งค่า** (การ์ด "สำรอง / ย้ายการตั้งค่า" ต้องกด "หยุด" ก่อน)
เลือกวิธีนำเข้า (แทนที่ / เพิ่มเป็นชุดใหม่) แล้วกด **นำเข้าไฟล์ SIRI export (.zip)** ตั้งค่ารวมและ Telegram เดิมไม่เปลี่ยน

**ทางที่ 2: สร้างไฟล์ config ของโฟลเดอร์ส่วนขยาย** (ใช้ Node.js)

```bash
node tools/siri-to-config.mjs "C:\Users\jatup\Downloads\SIRI_autopost_export.zip" --share-page-posts --codes-to-groups --all-groups --add-groups config/extra-groups.txt --footer "✨━━━━━━━━━━━━━━━━━━✨\n{🌐|💻|🔗|👉} สั่งทำรูปผ่านเว็บไซต์ : https://www.siristudiophoto.com/\n{📸|🖼️|✅|👉} ผลงาน : https://www.siristudiophoto.com/index/portfolio\n✨━━━━━━━━━━━━━━━━━━✨" --footer-position top --drop-images config/drop-images.txt --swap-images config/image-fixes --lead "C:\SIRI STUDIO PHOTO\Poster.jpg" --lead "C:\SIRI STUDIO PHOTO\Video.mp4" --replace "@970wfiou=>@siristudiophoto" --replace "@siristuiophoto=>@siristudiophoto" --replace "https://lin.ee/c2I3lh4=>https://line.me/R/ti/p/@siristudiophoto" --replace "ขออนุญาตแอดมินและสมาชิกในกลุ่มทุกท่านนะคะ=>{ขออนุญาตแอดมินและสมาชิกในกลุ่มทุกท่านนะคะ|ขออนุญาตแอดมินและสมาชิกทุกท่านนะคะ|ขออนุญาตแอดมินกลุ่มนะคะ|สวัสดีค่ะ ขออนุญาตแอดมินและสมาชิกนะคะ}" --set groupDelayMin=8 --set groupDelayMax=20 --set roundIntervalHours=1 --set roundJitterMin=60 --set longBreakEvery=6 --set longBreakMin=20 --set longBreakMax=45 --set skipChancePct=5 --set activeHoursEnabled=true --set activeStart=08:00 --set activeEnd=21:30 --set groupCooldownHours=12 --set recentAvoid=10 --set shuffleImages=true --set leadChancePct=100 --global minGapMin=5 --global dailyMaxPosts=30 --global blockPauseHoursMin=24 --global blockPauseHoursMax=48 --global failStreakPause=4
```

ได้ `config/autopost-config.json` ที่ส่วนขยายโหลดเองตอนติดตั้งใหม่ (ดูหัวข้อ "ย้ายไปเครื่องอื่น") ต้องใช้ Node.js 18 ขึ้นไป ทุกตัวเลือกไม่ใส่ก็ได้
- `--share-page-posts` = โพสต์ในเพจกลายเป็น "เนื้อหากลาง" ที่ทุกกลุ่มสุ่มใช้ได้
- `--codes-to-groups` = รหัสกลุ่มในโพสต์ของกลุ่ม ย้ายออกจากโพสต์ไปเป็น "ข้อความเฉพาะกลุ่ม" (ข้างลิงก์กลุ่ม) ตอนโพสต์ขึ้นบรรทัดแรกเอง (รหัส = คำที่โพสต์ใดโพสต์หนึ่งขึ้นต้นด้วย เช่น `#Jan240015`)
- `--keep-page-posts P055,P067,...` = โพสต์ในเพจที่ไม่เอามาใช้ (เก็บไว้ในชุดเพจที่ปิดอยู่)
- `--add-groups <ไฟล์>` = เพิ่มกลุ่มจากไฟล์รายการ (รูปแบบเดียวกับช่อง "เพิ่มหลายกลุ่มพร้อมกัน": หัวข้อหมวด, ลิงก์, `| ข้อความเฉพาะกลุ่ม`, `(หมายเหตุ)` = เพิ่มแบบปิด, `[1/วัน]` = จำนวนโพสต์ต่อวันของกลุ่ม) กลุ่มที่มีอยู่แล้วไม่เพิ่มซ้ำ แต่ `| ข้อความ` ในไฟล์ใช้แทนรหัสเดิมของกลุ่มนั้น
- `--footer "..."` = ข้อความเพิ่มในทุกโพสต์ของทุกชุด ใช้ `\n` แทนการขึ้นบรรทัด ใช้คำสุ่ม `{a|b}` ได้
- `--footer-position top|afterGreeting|end` = บนสุด (ใต้รหัสกลุ่ม ก่อนเนื้อหา), ต่อจากบรรทัดทักทาย (ค่าเริ่มต้น) หรือท้ายโพสต์
- `--all-groups` = ทุกโพสต์ของชุดกลุ่มใช้ได้กับทุกกลุ่ม แต่ละกลุ่มสุ่มเอง (ใช้หลัง `--codes-to-groups` อ่านรหัสจากโพสต์ของแต่ละกลุ่มแล้ว)
- `--lead <ไฟล์>` = รูป/วิดีโอที่แนบเป็นไฟล์แรกของทุกโพสต์ ใส่ได้หลายครั้ง เรียงตามลำดับที่ใส่ (jpg, png, webp, gif, mp4, mov, webm)
- `--replace "เดิม=>ใหม่"` = แทนที่ข้อความในทุกโพสต์ ตรงตัวอักษร ใส่ได้หลายครั้ง (ใส่คำสุ่ม `{a|b}` ในข้อความใหม่ได้)
- `--set ชื่อ=ค่า` = ค่าตั้งของชุด เช่น `groupDelayMin=8`, `activeHoursEnabled=true`
- `--global ชื่อ=ค่า` = ค่าตั้งรวม เช่น `dailyMaxPosts=30`
- `--drop-images <ไฟล์>` = รูปที่เอาออกจากทุกโพสต์ ใส่ id รูปบรรทัดละ 1 รูป หลัง `#` คือหมายเหตุ (ดู `config/drop-images.txt`) โพสต์ที่ไม่เหลือรูปของตัวเองยังโพสต์ได้ มีข้อความ + สื่อนำหน้า
- `--swap-images <โฟลเดอร์>` = รูปที่แก้แล้วใช้แทนรูปเดิม ตั้งชื่อไฟล์เป็น `<id รูป>.jpg` (หรือ .png .webp .gif) ระบบให้ id ใหม่ตามเนื้อไฟล์ เครื่องที่เคยโหลด config เก่าจะไม่ค้างรูปเดิม
- พิมพ์ค่าผิด (ชื่อค่าไม่มีจริง, ตัวเลขว่างหรือติดลบ, `true/false` ผิด, ตัวเลือกไม่มีในรายการ, เวลาไม่ใช่ `HH:MM`, id ใน `--keep-page-posts` ที่ไม่มีใน zip, id รูปที่ไม่มีใน zip, รูปเดียวกันอยู่ทั้งใน `--drop-images` และ `--swap-images`) คำสั่งหยุดและบอกว่าผิดตรงไหน ไม่เขียนไฟล์ config

## กันโดนบล็อก + หมุนเวียนเนื้อหา

ไม่มีวิธีไหนรับประกันว่า Facebook จะไม่บล็อก เพราะ Facebook ไม่เปิดเผยเกณฑ์ ระบบช่วยลดความเสี่ยงด้วยการโพสต์ช้า ๆ สม่ำเสมอ ไม่ซ้ำ และหยุดเองเมื่อ Facebook เตือน

**เนื้อหาไม่ซ้ำ (ตั้งในการ์ด "พฤติกรรมแบบสุ่ม" ของชุด)**
- ทุกกลุ่มสุ่มจากทุกโพสต์ในชุด (โพสต์ไม่ผูกกับกลุ่ม)
- **ไม่ใช้โพสต์ซ้ำในกลุ่มเดิม ภายใน N ครั้งล่าสุด** (ค่าเริ่มต้น 10) และพยายามไม่ใช้โพสต์เดียวกับกลุ่มก่อนหน้า ๆ
- **สลับลำดับรูปของโพสต์แบบสุ่ม** ทุกครั้ง (สื่อนำหน้ายังอยู่ก่อนเสมอ)
- **โอกาสแนบสื่อนำหน้า (%)**: 100 = ทุกโพสต์ ลดลงได้ถ้าไม่อยากให้ทุกโพสต์มีวิดีโอเดียวกัน
- คำสุ่ม `{a|b|c}` ในเนื้อหา คำทักทาย และข้อความลิงก์ ทำให้ข้อความแต่ละโพสต์ไม่เหมือนกันทุกตัวอักษร

**จังหวะโพสต์**
- **พักกลุ่มเดิมอย่างน้อย (ชั่วโมง)** (การ์ด "หน่วงเวลา และรอบ"): กลุ่มที่ยังพักไม่ครบจะยังไม่โพสต์ ระบบสลับกลุ่มที่พักครบแล้วขึ้นมาก่อน ถ้าไม่มีเลยจะรอ (สถานะ "รอกลุ่มที่เหลือพักครบเวลา") รอบหนึ่งยังโพสต์ครบทุกกลุ่มเหมือนเดิม และ "จำนวนรอบสูงสุด" นับเฉพาะรอบที่ครบ
- **จำนวนโพสต์ต่อวันของแต่ละกลุ่ม** (ช่อง "โพสต์ได้ … /วัน" ในตารางกลุ่ม): ตามกฎกลุ่ม เช่น กลุ่ม A ได้วันละ 1, กลุ่ม B วันละ 3, กลุ่ม C ไม่จำกัด (0)
  - นับใน 24 ชม. ย้อนหลัง (ไม่ใช่ตามวันที่) ปลอดภัยกับกลุ่มที่นับแบบ "1 โพสต์ต่อ 24 ชม." เช่น วันละ 1 โพสต์ไปตอน 10:00 จะโพสต์ได้อีกหลัง 10:00 ของวันถัดไป
  - กลุ่มที่ครบแล้วถูกข้ามในรอบนั้น (บันทึกว่า "ครบ N โพสต์ใน 24 ชม. ตามกฎกลุ่ม โพสต์ได้อีก …") กลุ่มอื่นโพสต์ต่อตามปกติ ถ้าทุกกลุ่มครบหมด ระบบรอจนกลุ่มแรกโพสต์ได้
  - นับทุกโพสต์ที่ออกไปจริงในกลุ่มนั้น รวมโพสต์ทดสอบ และโพสต์จากทุกชุดที่มีลิงก์กลุ่มเดียวกัน (ถ้าตั้งไม่เท่ากัน ใช้ค่าที่น้อยที่สุด)
  - ใช้กับ "โพสต์ทันที" และ "ทดสอบโพสต์" ด้วย กลุ่มที่ครบแล้วจะไม่ถูกโพสต์ซ้ำ
  - ในตารางกลุ่ม ช่องเป็นสีแดง = 24 ชม. นี้ครบแล้ว ชี้เมาส์ดูว่าโพสต์ไปแล้วกี่ครั้ง
  - ใช้ร่วมกับ "พักกลุ่มเดิมอย่างน้อย (ชั่วโมง)" ได้ ระบบใช้เงื่อนไขที่เข้มกว่า
- **โพสต์สูงสุดต่อวัน** (การ์ด "ตั้งค่ารวม"): นับรวมทุกชุดและโพสต์ทดสอบ ทุกวันสุ่มลดลงเล็กน้อย (85–100%) ครบแล้วรอถึงเช้าวันถัดไป (เวลาเริ่มของช่วงทำงาน หรือ 08:00 + สุ่มไม่กี่นาที)
- ช่วงเวลาทำงาน, หน่วงระหว่างกลุ่ม, สุ่มพักยาว, เว้นห่างขั้นต่ำทุกชุด ใช้ร่วมกันได้

**หยุดเองเมื่อมีสัญญาณอันตราย**
- ถ้าเจอกล่องข้อความของ Facebook เช่น "คุณถูกบล็อกชั่วคราว", "ใช้ฟีเจอร์นี้เร็วเกินไป", "จำกัดการโพสต์", "You're Temporarily Blocked", "We limit how often…" ระบบ **พักทุกชุด 24–48 ชั่วโมง** (ตั้งได้) แล้วกลับมาโพสต์เอง พร้อมส่ง Telegram แจ้งพร้อมภาพหน้าจอ
- ระบบอ่านเฉพาะกล่องแจ้งเตือนของ Facebook ไม่อ่านฟีด กฎกลุ่ม หรือข้อความที่เราพิมพ์ จึงไม่พักเพราะเจอคำว่า "สแปม" ในโพสต์คนอื่น
- ระบบดูกล่องแจ้งเตือนทั้งก่อนกดโพสต์และหลังกด ถ้าโพสต์ออกไปแล้วแต่ Facebook เตือนตามมา นับเป็นโพสต์สำเร็จ (นับในโควตาวันนี้และเวลาพักกลุ่ม) แล้วจึงพักทุกชุด
- **โพสต์ไม่สำเร็จติดกัน N ครั้ง** (ค่าเริ่มต้น 4): พัก 2–4 ชั่วโมง
- การพักไม่ทำให้รอบที่นัดไว้ช้ากว่านั้นมาเร็วขึ้น ชุดที่รอรอบ 12 ชม. อยู่ยังรอตามเวลาเดิม
- ระหว่างพัก กด **โพสต์ทันที** ได้ 1 โพสต์ (การพักยังอยู่) แต่ถ้ากดไว้ก่อนแล้ว Facebook เพิ่งเตือน ระบบยกเลิกคำสั่งนั้นและบันทึกว่า `ยกเลิก "โพสต์ทันที"…`
- อยากยกเลิกการพักเอง: กด "หยุด" แล้ว "เริ่มทำงาน" ใหม่
- สถานะ "วันนี้โพสต์แล้ว X / Y" และ "พักถึง…" ดูได้ในการ์ด "ตั้งค่ารวม" และ "ภาพรวมทุกชุด"

## สื่อนำหน้าทุกโพสต์ (รูป/วิดีโอ)

ในการ์ด "เนื้อหาโพสต์" มีกล่อง **"สื่อนำหน้าทุกโพสต์ในชุดนี้"**
- กด "+ เพิ่มรูป/วิดีโอ" ไฟล์ในกล่องนี้จะถูกแนบเป็นไฟล์แรก ๆ ของทุกโพสต์ในชุด แล้วตามด้วยรูปของแต่ละโพสต์
- เรียงจากซ้ายไปขวา กด ◀ เพื่อเลื่อนไฟล์ขึ้นก่อน กด × เพื่อเอาออก
- วิดีโอเก็บไว้ในเครื่องตามไฟล์เดิม (ไม่เกิน 200 MB) ระบบรอให้ Facebook อัปโหลดเสร็จก่อนกดโพสต์ (รอได้ถึง 10 นาที)
- แต่ละโพสต์ก็แนบวิดีโอเพิ่มเองได้ด้วยปุ่ม "+ แนบรูป/วิดีโอ"

## ข้อความเพิ่มในทุกโพสต์ (ลิงก์ / ช่องทางติดต่อ)

ในการ์ด "เนื้อหาโพสต์" ของแต่ละชุด มีช่อง **"ข้อความเพิ่มในทุกโพสต์ของชุดนี้"** และ **"ตำแหน่ง"**
- **ต่อจากบรรทัดทักทาย (ขออนุญาต… / สวัสดี…) ก่อนเนื้อหา** (ค่าเริ่มต้น): ถ้าโพสต์ไม่มีคำทักทาย จะขึ้นบรรทัดแรกแทน รหัสกลุ่มที่ขึ้นต้นโพสต์ยังอยู่ก่อนเสมอ
- **ท้ายโพสต์**: เว้น 1 บรรทัดแล้วต่อท้าย
- ใส่ให้ทุกโพสต์ในชุด รวมโพสต์ที่มีแต่รูป
- ถ้าโพสต์ไหนมีข้อความนี้อยู่แล้ว จะไม่ใส่ซ้ำ (ไม่สนช่องว่างที่ต่างกัน)
- ใช้คำสุ่ม `{...|...}` และ `{{code}}` (ข้อความเฉพาะกลุ่ม) ในข้อความนี้ได้
- Facebook ทำตัวหนาในโพสต์กลุ่มไม่ได้ ให้ใช้อีโมจิหรือเส้นคั่น (เช่น ✨━━━✨) เพื่อให้เด่น
- กด "ดูตัวอย่างสุ่ม" หรือ "ดูข้อความที่จะโพสต์" เพื่อดูข้อความจริง

## แท็กเพจในโพสต์ (ชื่อเพจตัวหนา กดไปที่เพจ)

ช่อง **"แท็กเพจในโพสต์"** (ใต้ "ตำแหน่ง") บรรทัดละ 1 เพจ `ชื่อเพจตรงตาม Facebook | ลิงก์เพจ` ค่าเริ่มต้น:

```
SIRI Studio Photo รับตัดต่อ รีทัช รูปติดบัตร รูปจบ สมัครงาน สมัครสอบ อัดรูป | https://www.facebook.com/KHRUSIRI
```

- โพสต์ที่มีชื่อเพจนี้: ตอนโพสต์จะพิมพ์ `@SIRI Studio Photo` แล้วกดเลือกเพจจากรายการที่ Facebook เด้งขึ้น ชื่อเพจในโพสต์จะเป็นตัวหนา กดแล้วไปที่เพจ (แบบที่คนพิมพ์ @ แท็กเพจเอง)
- แท็กเฉพาะจุดแรกที่เจอในโพสต์ ช่องว่างต่างกันได้ ตัวพิมพ์เล็ก/ใหญ่ไม่สน แต่ชื่อต้องครบ
- ถ้า Facebook ไม่เสนอเพจนี้ในรายการ จะลบ `@…` แล้วใส่ชื่อเป็นข้อความธรรมดาแทน (ดูได้ในบันทึก)
- โพสต์ยาวที่ใช้วิธีวาง (เกิน "พิมพ์ทีละตัวไม่เกิน") ก็แท็กได้: วางข้อความเป็นช่วง ๆ แล้วแท็กตรงกลาง
- ปุ่มตัวอย่างบอกว่าโพสต์นั้นจะแท็กเพจไหน ลบบรรทัดออก = ปิด
- ลิงก์เพจเป็นแค่บันทึกไว้ดู ไม่ได้ใส่ในโพสต์

## โพสต์ใช้กับกลุ่มไหน

ไม่มีการผูกโพสต์กับกลุ่ม **ทุกกลุ่มหยิบได้ทุกโพสต์** ในชุดนั้น
- แต่ละกลุ่มสุ่มโพสต์เอง ไม่ใช้โพสต์ซ้ำในกลุ่มเดิมภายใน N ครั้งล่าสุด และพยายามไม่ซ้ำกับกลุ่มก่อนหน้า (โหมด "เรียงตามลำดับ" = เรียงโพสต์ต่อกันทุกกลุ่ม)
- ข้อมูลเก่าที่เคยตั้ง "ใช้กับ" ไว้ ไม่มีผลแล้ว (ช่อง "ใช้กับ" และตัวกรอง "แสดงโพสต์" ถูกเอาออกจากหน้าตั้งค่า)
- อยากให้บางกลุ่มได้เนื้อหาต่างกัน: แยกเป็นอีกชุดโพสต์ (+ เพิ่มชุด) ใส่กลุ่มและโพสต์ของชุดนั้น

## ดาวน์โหลด / อัปโหลดการตั้งค่า

การ์ด **สำรอง / ย้ายการตั้งค่า** (ฝั่งขวา) ใช้สำรองข้อมูล หรือย้ายไปเครื่อง/Chrome โปรไฟล์อื่น

**ดาวน์โหลด** ได้ไฟล์ `fb-autopost-วันที่-เวลา.json`
- เลือกได้ว่าจะเอา **ทุกชุด + ตั้งค่ารวม** หรือ **เฉพาะชุดที่เลือกอยู่**
- "รวมรูปภาพในไฟล์" (ค่าเริ่มต้น เปิด): ไฟล์ใหญ่ขึ้นตามขนาดรูป แต่ย้ายเครื่องได้ครบ
- "รวม Telegram Bot Token" (ค่าเริ่มต้น ปิด): ถ้าเปิด ไฟล์จะมี Token อยู่ข้างใน ห้ามส่งไฟล์นั้นให้คนอื่น

**อัปโหลด** (ต้องกด "หยุด" ก่อน) เลือกวิธีนำเข้า แล้วเลือกไฟล์ ระบบแสดงสรุป (กี่ชุด/กลุ่ม/โพสต์/รูป) ให้ยืนยันก่อน
- **แทนที่การตั้งค่าทั้งหมด**: ชุดในเครื่องนี้ถูกแทนด้วยชุดจากไฟล์ ถ้าไฟล์ไม่มี Bot Token จะใช้ Token เดิมในเครื่อง
- **เพิ่มเป็นชุดใหม่**: ชุดจากไฟล์ถูกเพิ่มต่อท้าย ชุดเดิมและตั้งค่ารวมไม่เปลี่ยน ชื่อซ้ำจะเติม "(นำเข้า)"
- ไฟล์ที่ไม่มีรูป: โพสต์ที่อ้างรูปซึ่งไม่มีในเครื่องจะถูกตัดรูปนั้นออก (แจ้งจำนวนให้)
- ค่าที่ผิดรูปแบบในไฟล์ (เช่น แก้ไฟล์เองแล้วพิมพ์ตัวเลขผิด) จะถูกแทนด้วยค่าเริ่มต้น

## แจ้งเตือน Telegram + ภาพหน้าจอ

ตั้งค่าในการ์ด **แจ้งเตือน Telegram** (ฝั่งขวา):

1. ใน Telegram คุยกับ **@BotFather** พิมพ์ `/newbot` ตั้งชื่อ จะได้ **Bot Token** มาวางในช่อง
2. ส่งข้อความอะไรก็ได้หา bot ของเรา (หรือเพิ่ม bot เข้ากลุ่ม Telegram แล้วพิมพ์ในกลุ่ม)
3. กด **ดึง Chat ID** (ถ้ามีหลายแชท ระบบให้เลือกหมายเลข)
4. ติ๊ก **เปิดใช้** แล้วกด **ส่งข้อความทดสอบ**
5. ถ้าเปิด "แนบภาพหน้าจอ" Chrome จะถามสิทธิ์จับภาพหน้าจอ ให้กดอนุญาต (ถ้าเคยปฏิเสธ กดปุ่ม "อนุญาตจับภาพหน้าจอ")

สิ่งที่ส่งไป Telegram (เลือกเปิด/ปิดได้ทีละอย่าง):

| เหตุการณ์ | ข้อความ |
|---|---|
| โพสต์สำเร็จ | ✅ ชื่อกลุ่ม + ลิงก์, ชุด, รอบ (กลุ่มที่ x/y), เวลา, เวลากลุ่มถัดไป + **ภาพหน้าจอหลังโพสต์** |
| โพสต์ไม่สำเร็จ | ❌ ชื่อกลุ่ม + ลิงก์ + **สาเหตุ** + ภาพหน้าจอตอนที่พัง แล้ว **ข้ามไปกลุ่มถัดไปทันที** (ภายใน 30–90 วินาที ไม่รอเวลาหน่วงเต็ม) |
| จบรอบ | 📊 สรุปรายชื่อกลุ่มที่โพสต์สำเร็จ / ไม่สำเร็จ (พร้อมสาเหตุ) / สุ่มข้าม และเวลารอบถัดไป |
| เริ่ม / หยุด / ชุดครบรอบ | ▶️ ⏹ 🏁 |
| ปัญหาที่กระทบทุกกลุ่ม (ยังไม่ล็อกอิน, Facebook ขอยืนยันตัวตน) | ⚠️ **หยุดระบบอัตโนมัติ** พร้อมภาพหน้าจอ (ไม่ไล่โพสต์ให้พังทุกกลุ่ม) ส่งเสมอเมื่อเปิดแจ้งเตือน |

การ "ทดสอบโพสต์ 1 กลุ่ม" ก็แจ้งเตือนด้วย (มีป้าย 🧪 [ทดสอบ])

ภาพหน้าจอถ่ายจากหน้าต่างโพสต์ ถ้าหน้าต่างถูกย่อ (minimize) จะถ่ายไม่ได้และส่งเป็นข้อความอย่างเดียว แนะนำเปิด "ดึงหน้าต่างโพสต์ขึ้นมาด้านหน้า"
ส่ง Telegram ไม่สำเร็จจะไม่หยุดการโพสต์ แค่บันทึกไว้ในบันทึกการทำงาน

## ข้อควรรู้

- ส่วนขยายเปิด **หน้าต่างแยก** ไว้โพสต์ ไม่แตะแท็บที่ใช้อยู่ อย่าปิดหน้าต่างนั้นขณะกำลังโพสต์ (ถ้าปิด ระบบจะเปิดใหม่ในกลุ่มถัดไป)
- ต้องเปิด Chrome ทิ้งไว้ ถ้าปิดเครื่อง/ปิด Chrome ระบบจะทำต่อเมื่อเปิด Chrome ใหม่
- ตัวเลือก "ดึงหน้าต่างโพสต์ขึ้นมาด้านหน้า" ช่วยให้ Facebook ทำงานเสถียรกว่า หลังโพสต์เสร็จระบบจะคืนโฟกัสให้หน้าต่างเดิม ถ้าไม่อยากให้เด้งขึ้นมา ให้ปิดตัวเลือกนี้
- หน่วงขั้นต่ำจริงประมาณ 30 วินาที (ข้อจำกัดของ Chrome alarms)
- เว้นระหว่างรอบนับจาก **โพสต์กลุ่มสุดท้ายของรอบเสร็จ** ถึงเริ่มรอบใหม่
- กลุ่มที่ต้องรออนุมัติโพสต์ นับเป็นสำเร็จเมื่อส่งโพสต์แล้ว

### ความเสี่ยง

การโพสต์อัตโนมัติขัดกับข้อกำหนดการใช้งานของ Facebook การโพสต์เนื้อหาเดียวกันซ้ำ ๆ ในหลายกลุ่มอาจทำให้บัญชีถูกจำกัดการโพสต์หรือถูกระงับได้ แม้จะสุ่มพฤติกรรมแล้วก็ตาม แนะนำ:

- ตั้งหน่วงระหว่างกลุ่มอย่างน้อย 3–10 นาที และเว้นรอบหลายชั่วโมง
- ใช้หลายแบบโพสต์ + spintax ให้เนื้อหาแต่ละกลุ่มไม่เหมือนกัน
- เริ่มจากจำนวนกลุ่มน้อย ๆ ก่อน
- โพสต์เฉพาะกลุ่มที่อนุญาตให้โพสต์เนื้อหาแบบนั้น

| รอคิว (เว้นห่างจากโพสต์ก่อนหน้า) | ปกติ: ชุดนี้ถึงเวลาแล้วแต่เพิ่งมีโพสต์จากชุดอื่น ระบบรอตาม "เว้นห่างขั้นต่ำ" |
| Facebook ขอยืนยันตัวตน (checkpoint) | ระบบหยุดเอง เข้าไปยืนยันตัวตนเอง แล้วเพิ่มเวลาหน่วงก่อนกดเริ่มใหม่ |
| ส่ง Telegram ไม่สำเร็จ: Unauthorized | Bot Token ผิด คัดลอกจาก @BotFather ใหม่ |
| ส่ง Telegram ไม่สำเร็จ: chat not found | Chat ID ผิด หรือยังไม่เคยส่งข้อความหา bot กด "ดึง Chat ID" ใหม่ |
| จับภาพหน้าจอไม่ได้ | หน้าต่างโพสต์ถูกย่ออยู่ หรือยังไม่ได้อนุญาตสิทธิ์จับภาพ |

## โครงสร้างไฟล์

```
manifest.json      Manifest V3
background.js      ตัวจัดตารางเวลา (chrome.alarms) และขั้นตอนโพสต์แบบสุ่ม
content.js         คำสั่งย่อยบนหน้า Facebook (คลิก, พิมพ์, แนบรูป, กดโพสต์)
dashboard.html/css/js  หน้าตั้งค่าและดูสถานะ
lib/shared.js      ค่าเริ่มต้น, ชุดโพสต์, ข้อความเฉพาะกลุ่ม, spintax, ตรวจลิงก์, ฟังก์ชันสุ่ม
lib/telegram.js    ส่งข้อความ/รูปไป Telegram Bot API
lib/backup.js      สร้าง/อ่านไฟล์สำรองการตั้งค่า (ดาวน์โหลด/อัปโหลด/ไฟล์ config)
lib/zip.js         อ่านไฟล์ .zip (ใช้ตอนนำเข้า SIRI export)
lib/siri-import.js แปลง SIRI export เป็นชุดโพสต์/กลุ่ม/รูป
tools/siri-to-config.mjs  แปลง SIRI export zip เป็น config/autopost-config.json (Node.js)
config/            autopost-config.json = ทุกการตั้งค่า + รูป โหลดอัตโนมัติบนเครื่องใหม่
                   extra-groups.txt, drop-images.txt, image-fixes/ = ข้อมูลที่ใช้สร้าง config (ดูคำสั่งด้านบน)
icons/             ไอคอน
tools/test-online.mjs  ทดสอบโหมดออนไลน์ (background.js จริง + server จริง)
backend/SIRI.AUTOPOST.Server/  server .NET 10 + PostgreSQL (ตั้งค่าออนไลน์)
  Program.cs             เริ่มระบบ, ล็อกอิน (cookie), CORS ของ API เครื่องรัน, เสิร์ฟหน้าตั้งค่าของส่วนขยายที่ /app
  Data/                  ตาราง fbap_users, fbap_profiles (config), fbap_profile_images, fbap_devices, fbap_device_logs, fbap_device_commands + migrations
  Endpoints/             API เว็บ (/api/...) และ API เครื่องรัน (/api/device/..., header X-Device-Key)
  wwwroot/               หน้าล็อกอิน, หน้าจัดการ config/เครื่อง, web/shim.js (แปลง chrome.storage เป็นการเรียก server)
server/Dockerfile, server/docker-compose.yml  รัน server + PostgreSQL ด้วย Docker
```

ข้อมูลทั้งหมด (ตั้งค่า, รูป, บันทึก, Bot Token) เก็บใน `chrome.storage.local` บนเครื่อง ส่งออกไปที่ `api.telegram.org` เฉพาะตอนแจ้งเตือน และไปที่ server ของคุณเองเฉพาะเมื่อเชื่อมต่อโหมดออนไลน์ (config + รูป + สถานะ + บันทึกการทำงาน)

สิทธิ์ที่ขอ:
- `facebook.com`: เปิดกลุ่มและโพสต์
- `api.telegram.org`: ส่งแจ้งเตือน
- ทุกเว็บไซต์ (ขอเฉพาะตอนเปิด "แนบภาพหน้าจอ"): Chrome กำหนดว่าการจับภาพหน้าจอแท็บต้องใช้สิทธิ์นี้ ส่วนขยายใช้จับภาพเฉพาะหน้าต่างโพสต์ของตัวเองเท่านั้น

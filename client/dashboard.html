1 กลุ่มในชุดนี้

ช่อง ข้อความเฉพาะกลุ่ม ใช้ใส่ข้อความที่ต่างกันแต่ละกลุ่ม เช่น รหัสการซื้อการเข้ากลุ่ม ระบบจะใส่ไว้ บรรทัดแรก ของโพสต์ (หรือตรงตำแหน่ง {{code}} ถ้าใส่ไว้ในเนื้อหา) ปล่อยว่างได้

ช่อง โพสต์ได้ … /วัน = กฎของกลุ่มว่าโพสต์ได้กี่ครั้งใน 24 ชม. (เช่น 1 หรือ 3, 0 = ไม่จำกัด) ครบแล้วระบบข้ามกลุ่มนั้นไปก่อน กลุ่มอื่นโพสต์ต่อตามปกติ พ้น 24 ชม. นับจากโพสต์แรกค่อยโพสต์ได้อีก (ตัวเลขเป็นสีแดง = วันนี้ครบแล้ว)

เพิ่มหลายกลุ่มพร้อมกัน

วางบรรทัดละ 1 กลุ่ม · ใส่ข้อความเฉพาะกลุ่มหลัง | เช่น https://www.facebook.com/groups/123 | รหัส: ABC123 · บรรทัดที่ไม่ใช่ลิงก์ = ชื่อหมวด ใช้ตั้งชื่อกลุ่มด้านล่าง (เช่น "ชุดครุย 1", "ชุดครุย 2") · มีหมายเหตุในวงเล็บ เช่น (รอแอดมินอนุมัติ) = เพิ่มแบบปิดไว้ก่อน เปิดเองเมื่อพร้อม · จำนวนโพสต์ต่อวันตามกฎกลุ่ม ใส่ในวงเล็บเหลี่ยม เช่น https://www.facebook.com/groups/123 [1/วัน] หรือ [วันละ 3]

2 เนื้อหาโพสต์

ใส่ได้หลายแบบ รองรับคำสุ่ม {สวัสดีครับ|หวัดดีครับ} และ {{code}} = ข้อความเฉพาะกลุ่ม (ไม่ใส่ = ขึ้นบรรทัดแรกอัตโนมัติ) ระบบไม่กด Enter ระหว่างพิมพ์ จึงไม่เลือกคำที่ Facebook แนะนำ (แท็กคน/แฮชแท็ก) ทุกโพสต์ใช้ได้กับทุกกลุ่ม แต่ละกลุ่มสุ่มหยิบโพสต์เอง (ไม่ซ้ำโพสต์ล่าสุดของกลุ่มนั้น)

สื่อนำหน้าทุกโพสต์ในชุดนี้

รูป/วิดีโอในช่องนี้จะถูกแนบเป็นไฟล์แรก ๆ ของทุกโพสต์ในชุด (เรียงซ้ายไปขวา กด ◀ เพื่อเลื่อนขึ้นก่อน) แล้วตามด้วยรูปของแต่ละโพสต์

"บนสุด": ใต้รหัสกลุ่ม (ถ้ามี) ก่อนเนื้อหาทั้งหมด "ต่อจากบรรทัดทักทาย": ถ้าโพสต์ไม่มีบรรทัดทักทาย จะขึ้นเป็นบรรทัดแรกแทน ใส่ให้ทุกโพสต์ (รวมโพสต์ที่มีแต่รูป) ถ้าโพสต์ไหนมีข้อความนี้อยู่แล้วจะไม่ใส่ซ้ำ ใส่อีโมจิหรือเส้นคั่นเพื่อให้เด่นได้

ถ้าในโพสต์มีชื่อเพจนี้ ตอนโพสต์จะพิมพ์ @ แล้วเลือกเพจจากรายการของ Facebook ชื่อเพจจะขึ้นเป็นตัวหนา กดแล้วไปที่เพจ (แท็กเฉพาะจุดแรกที่เจอ) ถ้า Facebook ไม่เสนอเพจนี้ จะใส่ชื่อเป็นข้อความธรรมดาแทน ลิงก์เพจเป็นแค่บันทึกไว้ดู

ค้นหา / แทนที่ข้อความในทุกโพสต์ (เช่น เปลี่ยนไลน์แอด)

แทนที่ตรงตัวอักษร (ตัวพิมพ์เล็ก/ใหญ่ต้องตรง) ทั้งในข้อความโพสต์และข้อความต่อท้าย

3 หน่วงเวลา และรอบ (ของชุดนี้)

"พักกลุ่มเดิม" = กลุ่มที่เพิ่งโพสต์ไปจะไม่ถูกโพสต์ซ้ำจนกว่าจะครบชั่วโมงที่ตั้ง (ข้ามไปรอบหลัง) ช่วยไม่ให้แอดมินกลุ่มมองว่าสแปม

สุ่มเวลาในช่วง ต่ำสุด–สูงสุด ทุกกลุ่ม เมื่อโพสต์ครบทุกกลุ่มในชุด (1 รอบ) จะพักตามชั่วโมงที่ตั้ง + เวลาสุ่ม แล้วเริ่มรอบใหม่

ถึง

4 พฤติกรรมแบบสุ่ม (ของชุดนี้)

เนื้อหาแต่ละกลุ่มสุ่มหมุนเวียน: ไม่ซ้ำกับ N โพสต์ล่าสุดของกลุ่มนั้น และพยายามไม่ซ้ำกับกลุ่มก่อนหน้า ๆ ด้วย ลด "โอกาสแนบสื่อนำหน้า" (เช่น 60%) ถ้าไม่อยากให้ทุกโพสต์มีวิดีโอเดียวกัน

เชื่อมต่อเว็บ AutoPost (ตั้งเวลาโพสต์จากเว็บ)

ไม่ได้จับคู่

จับคู่เครื่องนี้กับเวิร์กสเปซบนเว็บ AutoPost แล้วโพสต์ที่ตั้งเวลาไว้บนเว็บ (บัญชี "Facebook · ชื่อเครื่อง") จะถูกโพสต์จากเครื่องนี้ด้วยวิธีเดียวกับชุดโพสต์ กลุ่มที่ตั้งไว้ในทุกชุดของเครื่องนี้จะไปเป็นกลุ่มให้เลือกบนเว็บ ทำงานแยกจากปุ่มเริ่ม/หยุด

ชุดโพสต์ทั้งหมดของเครื่องนี้ (กลุ่ม เนื้อหา รูป เวลา Telegram) จะขึ้นไปอยู่ที่หน้าเว็บ "ชุดโพสต์" ด้วย แก้ที่ไหนก็ได้ อีกฝั่งได้ของใหม่ภายใน ~30 วินาที (แก้พร้อมกันทั้งสองฝั่ง ใช้ของเว็บ) และกดเริ่ม/หยุด/ทดสอบโพสต์จากเว็บได้

เชื่อมต่อ server (ตั้งค่าออนไลน์)

ไม่ได้เชื่อมต่อ

ตั้งค่าจากหน้าเว็บของ server ได้จากทุกที่ เครื่องนี้ดึง config, ส่งสถานะ/บันทึก และรับคำสั่ง เริ่ม/หยุด ทุก 30 วินาที แก้ในเครื่องนี้ก็ส่งขึ้น server ให้เอง

ถ้า config บน server ยังว่าง ระบบจะอัปโหลดการตั้งค่าของเครื่องนี้ขึ้นไป ถ้ามีแล้ว เครื่องนี้จะใช้ config จาก server แทน

ภาพรวมทุกชุด

ตั้งค่ารวม

กันไม่ให้หลายชุดโพสต์ติด ๆ กัน ระบบโพสต์ทีละ 1 โพสต์เสมอ

กันโดนบล็อก

โควตาต่อวันสุ่มลดลงเล็กน้อยทุกวัน (85–100%) ครบแล้วรอถึงเช้าวันถัดไป ถ้าเจอข้อความเตือนของ Facebook (บล็อกชั่วคราว / ใช้ฟีเจอร์เร็วเกินไป / จำกัดการโพสต์) ระบบพักทุกชุดเองแล้วทำต่ออัตโนมัติ ถ้าต้องการยกเลิกการพักเอง กด "หยุด" แล้ว "เริ่มทำงาน" ใหม่

แจ้งเตือน Telegram

ยังไม่ได้อนุญาตให้จับภาพหน้าจอ
วิธีตั้งค่า
  1. ใน Telegram คุยกับ @BotFather พิมพ์ /newbot ตั้งชื่อ จะได้ Bot Token มาวางด้านบน
  2. ส่งข้อความอะไรก็ได้หา bot ของเรา (หรือเพิ่ม bot เข้ากลุ่ม Telegram แล้วพิมพ์ในกลุ่ม)
  3. กด "ดึง Chat ID" แล้วกด "ส่งข้อความทดสอบ"

ภาพหน้าจอถ่ายจากหน้าต่างโพสต์ แนะนำเปิด "ดึงหน้าต่างโพสต์ขึ้นมาด้านหน้า" เพื่อให้ถ่ายได้ทุกครั้ง
